# Für Entwickler: das `former:submitted`-Event

Nach erfolgreichem Absenden feuert Former ein `former:submitted`-Browser-Event mit den
übermittelten Feldwerten (und den unter „Automatisch mitgesendete Daten" beschriebenen
Zusatzdaten), das ein Theme z. B. für Google-Ads-Conversion-Tracking, einen
GTM/dataLayer-Push oder einen Salesforce-Aufruf nutzen kann.

Vollständige Details, die genaue Struktur des Event-`detail`-Objekts und Code-Beispiele
stehen in der `readme.md` des Plugins (`plugins/former/readme.md`).
