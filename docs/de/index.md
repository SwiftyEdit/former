# Former

Former baut beliebig viele Formulare per Drag & Drop zusammen - mit Datenbank-Speicherung,
E-Mail-Versand, Datei-Upload und Captcha-Schutz.

## Formular einbinden

Jedes Formular hat eine ID, die in der Formular-Übersicht angezeigt wird. Über den Shortcode
wird es an beliebiger Stelle eingebunden:

```
[plugin=former]form_id=3[/plugin]
```

Der Shortcode rendert das Formular auch, wenn das Plugin selbst (noch) nicht aktiviert ist -
das Absenden funktioniert aber erst, sobald Former unter **Addons** aktiviert wurde.
