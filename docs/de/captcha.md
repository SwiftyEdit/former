# Captcha

Standardmäßig ist beim Absenden ein einfaches Rechen-Captcha aktiv. Unter dem
**Einstellungen**-Tab des Plugins kann stattdessen Google reCAPTCHA v2 (mit Site-/Secret-Key)
gewählt werden - das gilt global für alle Formulare.

## Captcha pro Formular abschalten

Für einzelne Formulare, die z. B. nur angemeldete Benutzer sehen, lässt sich das Captcha in
den Formular-Einstellungen über **„Captcha für dieses Formular deaktivieren"** komplett
abschalten.
