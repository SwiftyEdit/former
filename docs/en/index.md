# Former

Former builds any number of forms via drag & drop - with database storage, e-mail delivery,
file uploads and captcha protection.

## Embedding a form

Every form has an ID, shown in the form list. Use the shortcode to embed it anywhere:

```
[plugin=former]form_id=3[/plugin]
```

The shortcode renders the form even if the plugin itself isn't activated yet - submitting it
only works once Former has been activated under **Addons**.
