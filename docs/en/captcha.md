# Captcha

By default, a simple math captcha runs on submission. Under the plugin's **Settings** tab,
Google reCAPTCHA v2 (with site/secret key) can be used instead - this applies globally to
all forms.

## Disabling captcha per form

For individual forms - e.g. ones only shown to logged-in users - the captcha can be turned
off entirely via **"Disable captcha for this form"** in that form's settings.
